# ELIS Documentation / Documentação do ELIS

English is the canonical language for API names, commands, compatibility
contracts, and release gates. The key user-facing pages include Brazilian
Portuguese summaries where the setup and proof boundaries matter.

Português do Brasil é o idioma de apoio para orientação de uso, configuração e
limites. Nomes de API, comandos, contratos de compatibilidade e gates de release
permanecem em inglês para evitar traduções divergentes.
