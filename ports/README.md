# Certification ports

This directory contains incomplete third-party ports. They are not discovered by
the ELIS demo browser and must not be described as finished or hardware-approved.

Promotion to `demos/` requires:

1. complete promised game content and child-appropriate presentation;
2. isolated upstream licensing, attribution, and reproducible asset conversion;
3. exact 16 MiB flash, 4 MiB Lua, bitmap, tile, bounded-work, and deterministic
   simulator proof;
4. sustained worst-case measurements on a named physical Lupi console.
